**Sonder The Voyage** es una representación frontend de la cadena de hoteles ubicada en Paddington, Londres. Este proyecto se centra en la experiencia del usuario y la presentación visual de los hoteles, utilizando tecnologías web fundamentales como HTML, CSS y JavaScript.

## Descripción del Proyecto

Este repositorio contiene el código fuente para la interfaz de usuario (frontend) del sitio web de Sonder The Voyage. El objetivo principal de esta implementación es proporcionar una experiencia de navegación fluida y atractiva para los potenciales huéspedes, mostrando la información relevante sobre los hoteles en Paddington y facilitando la exploración de sus servicios y comodidades.

**Características Principales (Implementadas en el Frontend):**

* **Página de Inicio Atractiva:** Diseño visualmente agradable con imágenes destacadas de los hoteles y una introducción a la marca Sonder The Voyage.
* **Listado de Hoteles:** Sección dedicada a mostrar los diferentes hoteles de la cadena en Paddington, con información resumida y enlaces a páginas de detalle.
* **Páginas de Detalle de Hotel:** Información completa sobre cada hotel, incluyendo galerías de imágenes, descripción de las habitaciones, servicios ofrecidos y ubicación.
* **Navegación Intuitiva:** Menú de navegación claro y fácil de usar para acceder a las diferentes secciones del sitio.
* **Interacciones Dinámicas:** Uso de JavaScript para mejorar la interactividad, como carruseles de imágenes, validación de formularios (si aplica en el frontend) y otros efectos visuales.

## Tecnologías Utilizadas

Este proyecto frontend se construyó utilizando las siguientes tecnologías web fundamentales:

* **HTML:** Estructura y contenido de las páginas web.
* **CSS:** Estilos y presentación visual del sitio (colores, tipografía, diseño, etc.).
* **JavaScript:** Interacciones dinámicas y comportamiento del lado del cliente.
